# Nyori на бесплатном хостинге (FadeHost)

Проверено по их документации на октябрь 2026. Бесплатный тариф: 1 бот, 256 МБ памяти, 0.25 vCPU, 3 ГБ диска в `/data`,
работает постоянно (polling не «засыпает»), карта не нужна, только подтверждённая почта. Названия кнопок в панели могут слегка отличаться.

## 1. Залить код на GitHub (нужен аккаунт GitHub)
1. Создай **приватный** репозиторий (Private!).
2. Загрузи в него содержимое папки Nyori: `bot.py`, папку `nyori/`, `requirements.txt`, `.gitignore`
   (кнопка **Add file → Upload files**, перетащи файлы и папку).
   Если веб-интерфейс GitHub не даёт создать папку `nyori/`: просто перетащи **саму папку** `nyori` целиком
   в окно загрузки, либо залей все файлы в корень — бот теперь заводится и так (в корне должны лежать `bot.py` и `config.py`, `db.py`, `automod.py` и остальные).
3. **Не загружай `.env`** — токен хранится только в панели хостинга. `.gitignore` это уже запрещает.

## 2. Создать бота на хостинге
1. Зарегистрируйся на fadehost.com, подтверди почту.
2. Создай приложение «Telegram bot», подключи свой репозиторий через GitHub App (приватный репозиторий поддерживается).
3. В таблице переменных окружения добавь:
   `TOKEN=<токен от BotFather>`  (именно `TOKEN`, так читает наш код)
4. Запусти деплой. В живой консоли должно появиться «Бот запущен» и «модель NudeNet загружена».

Прокси не нужен: у хостинга api.telegram.org не заблокирован. WARP на твоём ПК после переезда тоже не нужен.

## 3. Данные
Код при каждом деплое заменяется. База (`nyori.db`) и логи автоматически пишутся в `/data` — оно сохраняется между деплоями.

Перенос текущих настроек/варнов/доверенных с домашнего ПК (необязательно):
1. Останови бота на ПК (закрой окно), чтобы файл `nyori.db` был целым.
2. Положи `nyori.db` в репозиторий рядом с `bot.py` (в `.gitignore` он по умолчанию исключён — удали из него строки `nyori.db*`).
3. При первом запуске на хостинге база один раз скопируется в `/data`. Потом файл из репозитория можно удалить.
   Внимание: в базе ники и ID участников — репозиторий обязательно приватный.

Если не переносить — бот начнёт с чистого листа (настройки по умолчанию, группы появятся, как только бот увидит там сообщения).

## 4. Что просит бесплатный тариф
- Раз в несколько дней приходит письмо «бот ещё нужен?» — один клик по ссылке (или просто открой страницу бота в панели).
- Лимит трафика 1 ГБ/сутки — для чат-бота недостижим.
- Память 256 МБ: бот вместе с фильтром порно занимает ~130–160 МБ. Если упрётся (будет видно в графике памяти) —
  выключи фильтр порно в панели или возьми Starter ($2/мес, 1 ГБ).

## 5. Остановить бота на ПК
Перед первым запуском на хостинге **закрой бота на домашнем ПК**: два процесса с одним токеном будут конфликтовать
(Telegram отдаёт обновления только одному).

## 6. Если что-то не работает после обновления
- В первой строке консоли должна быть метка `сборка 2026-10-25-a` — значит, залиты свежие файлы. Другая метка или её нет — какой-то файл остался старым.
- Бот должен быть админом чата с правами: **удаление сообщений** и **блокировка участников**. Если права на удаление нет,
  бот сам напишет владельцу в личку (раз в час на чат).
- Вход новичков бот замечает и по служебному сообщению, и по смене статуса участника (это надёжнее, работает даже при скрытых входах).
- Настройки групп хранятся в базе: после обновления **новые значения по умолчанию** (например, уровень фильтра порно) применяются
  только к новым группам. В уже настроенных группах поменяй в панели вручную.

## 7. Второй «взгляд» для порно: ИИ-классификатор Marqo (необязательно)
NudeNet ищет конкретные части тела и на рисунках слабее. Классификатор Marqo/nsfw-image-detection-384 (22 МБ, Apache-2.0)
оценивает картинку целиком — это и есть второй взгляд: нарушение, если сработал любой из двух.
Без файлов модели бот работает как раньше (только NudeNet), в панели будет пометка «файлы модели не найдены».

1. На своём ПК (один раз, нужен интернет и ~1–2 ГБ под PyTorch):
   ```
   python -m venv exportenv
   exportenv\Scripts\activate
   pip install torch timm onnx onnxruntime numpy
   python tools/export_marqo_onnx.py
   ```
   Скрипт скачает модель, выгрузит её в ONNX, сам сверит результат с оригиналом и выдаст два файла:
   `marqo_nsfw_384.onnx` и `marqo_nsfw_384.json`. Он напечатает «Классы модели: [...]» — если там нет `NSFW`, пришли мне эту строку.
2. Загрузи **оба** файла в корень репозитория рядом с `bot.py` (файл ~22 МБ, лимит веб-загрузки GitHub — 25 МБ).
3. Перезапусти бота. В панели группы вместо «файлы модели не найдены» будет «вкл».

Память: классификатор добавляет примерно 50 МБ. Весь бот с обеими моделями — около 190 МБ в обычной работе и до ~230 МБ на пике,
то есть в бесплатные 256 МБ он влезает впритык. Если хостинг начнёт перезапускать бота (OOM) — выключи «ИИ-классификатор» в панели
(тогда он вообще не загружается и память не занимает) или возьми Starter ($2/мес, 1 ГБ).
Классификатор проверяет фото, стикеры и превью; кадры видео проверяет только NudeNet.
